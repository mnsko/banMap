          ABOUT THIS PROJECT

          A decoy, built to listen.

          This observatory collects automated connections to an isolated Cowrie SSH honeypot. Its shell is simulated; it is not the server’s administrative SSH service.

          Passwords and usernames are published only in aggregates shared by at least 3 distinct IP addresses. Long strings and likely tokens are masked. The live feed never contains passwords.

          IP addresses are processed for security research. Raw events are kept for 90 days, then deleted; anonymous daily counts remain. Network geolocation is approximate and does not identify a person. Commands and defanged domains are inert text.

          World outline: Natural Earth (public domain). Map tiles: CARTO and OpenStreetMap contributors. Tiles require requests to CARTO; no analytics or tracking scripts are loaded.
